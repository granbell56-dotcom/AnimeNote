Questions fréquentes

Comment sont données les notes ?

Les notes sont affichées sur 5 étoiles et proviennent des données renseignées pour chaque animé.

Comment regarder un animé ?

Ouvre sa fiche puis choisis le lien de visionnage lorsqu'il est disponible.

Comment trouver un genre ou une plateforme ?

Les plateformes restent visibles dans l'en-tête ; le menu « Genre » se construit à partir des animés disponibles. Les filtres se combinent.
